SHOW MONTHLY SETTLEMENT REPORT

You just log in using 1 account to show the settlement report for 3 different account types:

tmsb express mart

There are many ways to show the settlement report, but each method has pros and cons.

1. Monthly

Activity Reporting
└ Settled Transaction

Analyzing settled transactions monthly is easy, but you will face a difficult incorrect date format issue.

For example, the July record will show another month due to an error reading the date, like 01-07-2026, so the Excel program will read it as 07 January 2026.

The monthly settlement report will provide 3 different .csv files for 3 different accounts.

Online retrieval is limited to the past 6 months' record history.

Each transaction record just shows the TID, so it won't show which outlet made the sale. You'll need to download the report from the portal and VLOOKUP it with your TID list.

Solution: Click here to use the program to fix the date format and merge the 3 account types into one Excel file.

2. Daily

Activity Reporting
└ Statement of Account

Analyzing settled transactions monthly is harder than the previous method, but you will never face the incorrect date format problem.

You need to download each day's report day by day. For example, if you want to analyze records for the whole of July 2026, you need to download the daily report 31 times.
