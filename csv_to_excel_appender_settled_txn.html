Settled Txn → Excel Splitter

Drop in one or more raw settled-txn-<merchantID>-<start>-to-<end>.csv files at once — daily, weekly, or monthly, any number of merchants, mixed freely. Each merchant is split into its own sheet, the category is auto-detected from the date range (no need to pick it), and every Settlement Date / Transaction Time value is normalised to unambiguous DD-MMM-YYYY HH:MM:SS text (e.g. 01-Jul-2026 05:47:10) so nothing can be misread by Excel — even if you later use Text to Columns.
